생활치트키

개인정보처리방침

시행일: 2026년 10월 6일

1. 개요

"생활치트키 자동화"(이하 "서비스")는 생활치트키 운영자가 본인 소유의 인스타그램(@life.cheatkey.kr)과 유튜브(@life.cheatkey_kr) 계정을 운영하기 위해 만든 내부 도구입니다. 일반 이용자가 가입하거나 로그인하는 서비스가 아닙니다.

2. 처리하는 정보

  • 운영자 계정 정보: Google·Meta가 발급한 인증 토큰, 운영자 채널의 게시물·통계 정보. 운영자 계정에 콘텐츠를 게시하고 성과를 분석하는 데만 씁니다.
  • 공개 댓글: 운영자 게시물에 달린 댓글의 작성자 아이디와 내용. 댓글에 답하거나 요청한 정보를 메시지로 보내는 용도로만 처리하며, 처리 후 30일 안에 삭제합니다.

서비스는 위 정보 외의 개인정보를 수집하지 않으며, 광고 목적으로 이용자를 추적하지 않습니다.

3. Google 사용자 데이터

서비스는 YouTube Data API와 YouTube Analytics API를 통해 운영자 본인 채널에 동영상을 올리고 통계를 조회합니다. Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한된 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

서비스는 YouTube API 서비스를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

4. 보관과 보안

모든 정보는 운영자가 관리하는 컴퓨터에만 저장되며 외부 서버에 올리지 않습니다. 인증 토큰은 공개 저장소에 올리지 않고 접근이 제한된 파일에 보관합니다.

5. 제3자 제공

처리한 정보를 판매하거나 제3자에게 제공하지 않습니다. 단, 법령에 따라 요구되는 경우는 예외로 합니다.

6. 삭제 요청

본인의 댓글 등 서비스가 처리한 정보의 삭제를 원하시면 인스타그램 @life.cheatkey.kr로 DM을 보내주세요. 확인 후 7일 안에 삭제하고 결과를 알려드립니다.

운영자는 Google 계정의 서드파티 앱 접근 권한 페이지와 인스타그램 설정에서 언제든 서비스의 접근 권한을 해제할 수 있습니다.
